# Survivor Workbench

An installable, offline-first companion app for **ARK: Survival Ascended** and **ARK: Survival Evolved**.

## Features

- Blueprint crafting-skill calculator
- Custom recipe ingredient calculator
- Recipe-goal calculator for target stats
- Locally saved recipes
- Offline PWA support
- Mobile-friendly interface with animated Jerboa companions

## Use the app

Open the GitHub Pages deployment, or download the repository and open `index.html` through a local web server.

The app stores saved recipes in the browser using `localStorage`. No account, server, or internet connection is required after the initial installation.

## Repository structure

```text
Survivor-Workbench/
├── assets/
├── index.html
├── manifest.webmanifest
└── service-worker.js
```

## Install on a phone

1. Open the GitHub Pages site in Safari or Chrome.
2. Choose **Add to Home Screen** or **Install app**.
3. Launch Survivor Workbench from the new home-screen icon.
